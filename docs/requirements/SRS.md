# Специфікація вимог до програмного забезпечення
## GestureMouse v1.0

**Версія документа:** 1.0  
**Дата:** 2026 

---

## 1. Вступ

### 1.1 Мета
Цей документ описує функціональні та нефункціональні вимоги до системної утиліти GestureMouse.

### 1.2 Область застосування
Система призначена для керування курсором миші за допомогою жестів рук через веб-камеру.

---

## 2. Функціональні вимоги

### FR-01: Виявлення руки
- Система повинна виявляти руку у кадрі веб-камери в режимі реального часу
- Виявлення має працювати при різному освітленні (природне / штучне)
- Затримка виявлення не повинна перевищувати 100 мс

### FR-02: Розпізнавання жестів
| ID | Жест | Дія |
|----|------|-----|
| G-01 | Відкрита долоня (4+ пальців) | Переміщення курсору |
| G-02 | Вказівний палець | Клік лівою кнопкою |
| G-03 | Два пальці (V) | Клік правою кнопкою |
| G-04 | Рух вниз з відкритою долонею | Прокрутка вниз |
| G-05 | Рух вгору з відкритою долонею | Прокрутка вгору |
| G-06 | Стиснутий кулак у русі | Перетягування |

### FR-03: Керування курсором
- Переміщення курсору має бути плавним (EMA-згладжування)
- Точність позиціонування: ±5 пікселів
- Підтримка роздільної здатності екрана до 4K

### FR-04: Системний трей
- Наявність іконки у системному треї
- Меню: "Налаштування", "Пауза", "Вихід"

### FR-05: Налаштування
- Регулювання чутливості переміщення
- Вибір індексу камери
- Збереження налаштувань між сеансами

---

## 3. Нефункціональні вимоги

### NFR-01: Продуктивність
- Обробка відео: не менше 30 FPS
- Використання CPU: не більше 25% на одному ядрі

### NFR-02: Надійність
- Коректне завершення при відключенні камери
- Відновлення після помилок OpenCV без краша програми

### NFR-03: Сумісність
- Windows 10/11 (x64)
- Ubuntu 20.04+ (x64)

### NFR-04: Безпека
- Відсутність мережевих з'єднань
- Відсутність збереження відеопотоку на диск

---

## 4. Обмеження

- Не підтримується темна шкіра при поганому освітленні (обмеження HSV-методу)
- Одночасно відстежується лише одна рука
- Потребує фізичну веб-камеру (не підтримується віртуальна камера)
