11 *
12 * ### Платформна абстракція
13 * Реалізація приховує платформо-залежний код за допомогою `#ifdef`:
14 *
15 * | Платформа | API симуляції | Файл |
16 * |-----------|---------------|------|
17 * | Windows 10/11 | `SendInput()` (user32.dll) | MouseController.cpp |
18 * | Linux (X11) | `XTestFakeMotionEvent()` (xtst) | MouseController.cpp |
19 *
20 * ### EMA-згладжування
21 * Для усунення тремтіння курсора використовується
22 * **Exponential Moving Average (EMA)**:
23 *
24 * ```
25 * smoothed_x = prev_x + α * (raw_x - prev_x)
26 * ```
27 * де α = `m_smoothing` ∈ (0, 1].
28 * - α → 1.0: миттєве слідування (без згладжування)
29 * - α → 0.0: сильне згладжування, велика інерція
30 *
31 * @see GestureResult
32 * @see InputSimulator
33 */
