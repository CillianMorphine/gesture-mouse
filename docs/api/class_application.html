Detailed Description

Іконка у системному треї

Головний клас програми — керує життєвим циклом усіх компонентів.

Клас не підлягає копіюванню (Rule of 5). Типове використання:

int main(int argc, char** argv) {
Application app(argc, argv);
return app.run(); // блокує до зупинки
}

◆ run()

int Application::run ( )
nodiscard

Запускає головний цикл програми.

Блокує до виклику stop().

Послідовність виконання:

  1. Відображає іконку в системному треї.
  2. Входить у нескінченний цикл: захват кадру → розпізнавання → дія.
  3. Повертає керування після того, як m_running стає false.
Returns
EXIT_SUCCESS (0) при нормальному завершенні, EXIT_FAILURE (1) якщо камеру не вдалося відкрити.
Note
Викличте stop() з іншого потоку або з обробника сигналу, щоб завершити цикл.

void Application::stop ( )
noexcept

Надсилає сигнал завершення головному циклу.

Метод є потокобезпечним завдяки std::atomic<bool>. Цикл завершується після поточної ітерації (не миттєво).

Типові сценарії виклику:

  • Клік "Вихід" у системному треї → TrayIcon::onExit()
  • Сигнал SIGINT / SIGTERM (Ctrl+C)
  • Команда –no-gui в тестовому режимі
Note
noexcept — метод ніколи не кидає виключень.
