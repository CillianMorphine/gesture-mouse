Detailed Description

Статичний потокобезпечний логер з виводом у файл і stdout.

Всі методи статичні — логер є singleton за поведінкою, але реалізований без патерну Singleton (простіше тестувати).

Note
Клас не підлягає інстанціюванню (конструктор видалений).

Записує повідомлення з рівнем, часовою міткою та позицією в коді.

Зазвичай викликається через макроси LOG_*, які автоматично підставляють __FILE__ та __LINE__.

Формат рядка: [TIMESTAMP] [LEVEL] message (file:line)

Parameters

messageТекст повідомлення (UTF-8).
fileІм'я файлу (зазвичай FILE).
lineНомер рядка (зазвичай LINE).
