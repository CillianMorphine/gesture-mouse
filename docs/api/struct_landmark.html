Detailed Description

Координата однієї ключової точки (landmark) руки у 3D-просторі.

У поточній реалізації z завжди 0 (2D-трекінг). Структура сумісна з форматом MediaPipe Hand Landmarks для можливого майбутнього переходу.

Координати нормалізовані: (0,0) = лівий верхній кут кадру, (1,1) = правий нижній кут.
