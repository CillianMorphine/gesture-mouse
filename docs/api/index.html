🖱️ GestureMouse — Системна утиліта керування курсором жестами

Опис проекту

GestureMouse — це системна утиліта, яка дозволяє керувати курсором миші за допомогою жестів рук, розпізнаних через веб-камеру в режимі реального часу. Програма використовує алгоритми комп'ютерного зору для відстеження положення руки та перетворення жестів у команди керування курсором.

Основні можливості

  • 🎯 Переміщення курсору за допомогою руки
  • 👆 Клік лівою кнопкою миші (вказівний жест)
  • ✌️ Клік правою кнопкою миші (жест двох пальців)
  • 📜 Прокрутка (жест відкритої долоні)
  • ⚙️ Налаштування чутливості та зони відстеження
  • 🖥️ Системний трей з іконкою управління

Вимоги

Програмні вимоги

  • C++17 або новіший стандарт
  • CMake 3.15+
  • OpenCV 4.x
  • Windows 10/11 або Ubuntu 20.04+

Апаратні вимоги

  • Веб-камера (мінімум 720p, 30 fps)
  • Процесор: Intel Core i3 або еквівалент
  • RAM: мінімум 4 ГБ

Збірка та запуск

Клонування репозиторію

git clone https://github.com/CillianMorphine/gesture-mouse.git
cd gesture-mouse

Збірка (Linux)

mkdir build && cd build
cmake ..
make -j4
./gesture_mouse

Збірка (Windows)

mkdir build && cd build
cmake .. -G "Visual Studio 17 2022"
cmake --build . --config Release
.\Release\gesture_mouse.exe

Використання

  1. Запустіть утиліту
  2. Направте камеру так, щоб рука була у кадрі
  3. Підніміть руку — курсор почне рухатися
  4. Використовуйте жести для кліків та прокрутки
