Detailed Description

Модуль симуляції введення миші на основі розпізнаних жестів.

MouseController перетворює абстрактні GestureResult у конкретні системні події (переміщення, кліки, прокрутка).

EMA-згладжування

Для усунення тремтіння курсора використовується Exponential Moving Average (EMA):

smoothed_x = prev_x + α * (raw_x - prev_x)

де α = m_smoothing ∈ (0, 1].

  • α → 1.0: миттєве слідування (без згладжування)
  • α → 0.0: сильне згладжування, велика інерція
