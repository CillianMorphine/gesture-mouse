Detailed Description

Зручні макроси для виклику Logger::log() з автоматичним FILE/__LINE__.

Обгортка do { ... } while(false) дозволяє безпечно використовувати макроси в конструкціях if/else без фігурних дужок:

if (error)
LOG_ERROR("Something went wrong"); // безпечно
else
LOG_INFO("All good"); // безпечно
