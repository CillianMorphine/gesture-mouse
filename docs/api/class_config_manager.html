Detailed Description

Зчитує та зберігає налаштування у форматі key=value.

Підтримує типізований доступ через шаблонний метод get<T>(). При відсутності ключа або помилці парсингу повертає defaultValue.

Приклад:
ConfigManager cfg("config/settings.txt");
float smooth = cfg.get<float>("mouse.smoothing", 0.3F);
int camIdx = cfg.get<int>("camera.index", 0);
bool debug = cfg.get<bool>("debug.show_window", false);
