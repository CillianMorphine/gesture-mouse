Про роботу

Проєкт присвячений розробці системної утиліти, яка дозволяє керувати курсором миші без фізичного контакту — лише за допомогою жестів руки перед веб-камерою.

Актуальність теми обумовлена зростаючим попитом на безконтактні інтерфейси: від медицини та реабілітації до доступності для людей з обмеженими можливостями та промислової автоматизації.

Утиліта реалізована на C++17 з використанням бібліотеки OpenCV 4 для обробки відеопотоку в режимі реального часу та платформо-залежного API (Win32 / X11) для симуляції введення.

Мета та завдання

Мета роботи — розробити кросплатформну системну утиліту, що забезпечує інтуїтивне та точне керування курсором миші через розпізнавання жестів рук у режимі реального часу.

  1. 01

    Аналіз існуючих рішень

    Огляд методів комп'ютерного зору для виявлення руки: аналіз тілесного кольору, детектори особливих точок, нейромережеві підходи (MediaPipe).

  2. 02

    Проєктування архітектури

    Розробка шаруватої архітектури системи з модулями: розпізнавання жестів, керування курсором, конфігурації та інтерфейсу.

  3. 03

    Реалізація алгоритмів

    Імплементація HSV-сегментації, аналізу опуклої оболонки та EMA-фільтру для плавного переміщення курсору.

  4. 04

    Тестування та валідація

    Написання модульних тестів (Google Test), вимірювання затримки, точності та стабільності за різних умов освітлення.

  5. 05

    Оцінка результатів

    Порівняння з аналогами, аналіз обмежень методу тілесного кольору, окреслення напрямів подальшого розвитку.

03

Методологія

1. Захват кадру

Отримання відеопотоку з веб-камери через cv::VideoCapture з частотою ≥ 30 FPS.

→

2. HSV-сегментація

Перетворення BGR→HSV, виділення тілесного кольору за діапазоном, морфологічна обробка маски.

→

3. Виявлення руки

Пошук контурів, вибір найбільшого, аналіз опуклої оболонки, обчислення центру мас.

→

4. Класифікація жесту

Підрахунок підйнятих пальців евристичним методом → визначення типу жесту з впевненістю > 0.6.

→

5. Керування мишею

EMA-згладжування координат → відправка події через SendInput (Win32) або XTest (X11).

Висока продуктивність

Обробка відео ≥ 30 FPS на звичайному ПК без виділеної GPU, затримка реакції < 100 мс.

Точне керування

Відхилення курсору ≤ 5 пікселів, EMA-фільтр усуває тремтіння без втрати чуйності.
