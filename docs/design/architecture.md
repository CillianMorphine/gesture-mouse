# Архітектура системи GestureMouse

## Огляд

GestureMouse побудований за принципом **шаруватої архітектури** з чітким розподілом відповідальності між модулями.

```
┌─────────────────────────────────────────────┐
│              Шар UI (TrayIcon, Settings)     │
├─────────────────────────────────────────────┤
│         Ядро (Application, ConfigManager)   │
├──────────────────────┬──────────────────────┤
│  Gesture Module      │   Input Module       │
│  (HandTracker,       │   (MouseController,  │
│   GestureClassifier) │    InputSimulator)   │
├──────────────────────┴──────────────────────┤
│         Утиліти (Logger, Timer)             │
├─────────────────────────────────────────────┤
│      ОС / Апаратний рівень (OpenCV, Win32/X11)│
└─────────────────────────────────────────────┘
```

## Компоненти

### 1. Application (Ядро)
- Точка входу та головний цикл програми
- Ініціалізує всі модулі та координує їх роботу
- Керує станом (запущено / зупинено)

### 2. GestureRecognizer (Модуль жестів)
- **HandTracker**: виявлення руки через аналіз тілесного кольору в HSV-просторі
- **GestureClassifier**: класифікація жесту на основі ключових точок (landmarks)
- Повертає структуру `GestureResult` з типом жесту та координатами

### 3. MouseController (Модуль введення)
- Перетворює `GestureResult` у системні події миші
- Реалізує згладжування переміщення (EMA-фільтр)
- Абстрагує платформо-залежний код через `#ifdef`

### 4. ConfigManager
- Читає/записує налаштування у простий текстовий формат `key=value`
- Надає типізований доступ через шаблонний метод `get<T>()`

### 5. UI (TrayIcon, SettingsWindow)
- Системна іконка трею для управління програмою
- Вікно налаштувань (чутливість, параметри камери)

## Потік даних

```
Камера → HandTracker → GestureClassifier → MouseController → ОС
             ↓                                    ↑
         ConfigManager ───────────────────────────┘
```

## Потоки виконання

- **Головний потік**: UI, системний трей
- **Потік обробки**: захват кадрів з камери → розпізнавання → управління мишею

## Рішення щодо проектування

| Рішення | Обґрунтування |
|---------|---------------|
| OpenCV для захвату відео | Кросплатформна, добре задокументована бібліотека |
| HSV-сегментація тілесного кольору | Не потребує ML-моделі, швидко працює на CPU |
| EMA-згладжування курсора | Усуває тремтіння без великої затримки |
| `#ifdef` для платформ | Мінімальні залежності, без сторонніх абстракцій |
| ConfigManager без JSON-бібліотеки | Спрощення збірки, відсутність залежностей |
