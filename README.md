## Опис проекту

**GestureMouse** — це системна утиліта, яка дозволяє керувати курсором миші за допомогою жестів рук, розпізнаних через веб-камеру в режимі реального часу. Програма використовує алгоритми комп'ютерного зору для відстеження положення руки та перетворення жестів у команди керування курсором.

### Основні можливості

- 🎯 Переміщення курсору за допомогою руки
- 👆 Клік лівою кнопкою миші (вказівний жест)
- ✌️ Клік правою кнопкою миші (жест двох пальців)
- 📜 Прокрутка (жест відкритої долоні)
- ⚙️ Налаштування чутливості та зони відстеження
- 🖥️ Системний трей з іконкою управління

## Вимоги

- C++17 або новіший стандарт
- CMake 3.15+
- OpenCV 4.x

## Збірка та запуск

### Клонування репозиторію
```bash
git clone https://github.com/CillianMorphine/gesture-mouse.git
cd gesture-mouse
```

### Збірка (Linux)
```bash
mkdir build && cd build
cmake ..
make -j4
./gesture_mouse
```

### Збірка (Windows)
```bash
mkdir build && cd build
cmake .. -G "Visual Studio 17 2022"
cmake --build . --config Release
.\Release\gesture_mouse.exe
```

## Використання

1. Запустіть утиліту
2. Направте камеру так, щоб рука була у кадрі
3. Підніміть руку — курсор почне рухатися
4. Використовуйте жести для кліків та прокрутки

### Що і як документувати

Кожен **публічний** клас, метод, функція та нетривіальний член класу **обов'язково** мають коментар.

#### Обов'язковий мінімум для методу:

```cpp
/**
 * @brief Одне речення — що робить метод.
 * @param name Опис параметра.
 * @return Що повертає.
 */
ReturnType methodName(Type name);
```

#### Повний коментар (для складних методів):

```cpp
/**
 * @brief Коротко.
 * @details Детально: алгоритм, обмеження, чому саме такий підхід.
 * @param[in]     input  Вхідний параметр.
 * @param[out]    result Вихідний параметр.
 * @param[in,out] buf    Вхідно-вихідний.
 * @return Що повертає і при яких умовах.
 * @throws std::runtime_error якщо X.
 * @pre  Передумова.
 * @post Постумова.
 * @note Важлива нотатка.
 * @see RelatedClass::relatedMethod()
 */
```

#### Член класу (однорядковий коментар):

```cpp
float m_smoothing{0.3F}; ///< Коефіцієнт EMA-згладжування [0..1]
```

### Правила для контрибуторів

1. **Новий публічний метод** → обов'язково `@brief` + `@param` + `@return`
2. **Зміна поведінки** → оновлюй коментар у **тому ж коміті**
3. **Складний алгоритм** → документуй `@details` з поясненням **чому**, не лише **що**
4. **Перед push** → запусти `doxygen Doxyfile` та перевір `doxygen-warnings.log`
